# Irja Payments Gateway

Cloudflare Workers payment gateway for the Irja storefront.

- Verifone Hosted Payments Page for PCI SAQ A checkout
- D1 and KV for orders, audit events, and caching
- Landsbankinn settlement reconciliation
- No card data enters or is stored by this service

See [README.md](./README.md) for development and integration details.
